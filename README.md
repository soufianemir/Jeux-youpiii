# Le Royaume magique de Constance

Mini-jeu éducatif féerique pensé pour une enfant de 5 ans : labyrinthe, différences, chiffres, additions, lettres/mots et mémoire.

## Principes
- aucune inscription ;
- aucun backend ;
- progression enregistrée localement ;
- gros boutons tactiles ;
- pas de chrono ni d'écran d'échec ;
- fonctionne comme un site statique sur Vercel.

## Déploiement Vercel
Importe simplement ce dépôt dans Vercel. Aucun build command ni variable d'environnement n'est requis.
